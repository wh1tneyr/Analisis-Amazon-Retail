# 🛒 Análisis de Ventas en Amazon: Un Enfoque en E-commerce y Retail
| Proyecto de análisis de datos | Mayo 2025

## 📌 Descripción

El presente análisis tiene como finalidad explorar y comprender el comportamiento de las ventas en Amazon, con el fin de identificar patrones relevantes y oportunidades de mejora. Se busca analizar los productos más rentables, el comportamiento de compra y el uso de métodos de pago, para así optimizar la estrategia de e-commerce.

## 🎯 Objetivos del Proyecto

- Analizar datos de ventas de Amazon para identificar patrones y comportamientos de compra.
- Detectar oportunidades de mejora en la conversión de pedidos e ingresos.
- Evaluar el impacto de variables como método de pago, tipo de producto y día de la semana en las ventas.
- Extraer insights accionables para optimizar la estrategia comercial.
- Visualizar los resultados mediante un dashboard interactivo en Power BI.

## 🚀 Cómo ejecutar el proyecto

- Clonar el repositorio:

```git clone https://github.com/wh1tneyr/Analisis-Amazon-Retail.git```
```cd Analisis-Amazon-Retail```

- Crear y activar el entorno virtual (opcional pero recomendado):
```python -m venv venv```

   - En Windows: ```venv\Scripts\activate```
   - En macOS/Linux: ```source venv/bin/activate```

- Instalar las dependencias:

```pip install -r requirements.txt```

- Ejecutar el notebook:

Abre notebooks/Analisis_Amazon_Retail.ipynb con Jupyter Notebook o VS Code.
